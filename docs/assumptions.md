# Assumptions

1. 当前版本优先保证“可运行可演示”，前端使用真实 API 联调，缺失复杂业务规则后续迭代。
2. 姓名字段可为空，AI 分析只传匿名学号或 ID，不传姓名。
3. 若未配置 DeepSeek API Key，系统提供降级文本，不阻塞演示流程。
4. 示例数据采用单学期（2025-2026-1），至少 1 门课程、2 个班、60 名学生。
5. 题目逐题得分可后续导入；若未导入，题目分析返回结构化默认值（0 分基线）。
6. 默认数据库为 SQLite，可通过 `DATABASE_URL` 切换 PostgreSQL。
7. Node 建议 LTS 版本；若本机高版本与 `vue-tsc` 不兼容，构建以 `vite build` 为准。
