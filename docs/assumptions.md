# Assumptions

1. 当前版本以“教师可演示、毕设可答辩”为第一优先级，已完成 Excel 模板导出、Word 版试卷分析文档导出和文字分析输出。
2. 业务中心采用 `AnalysisRun`，即“一门课 + 一个班 + 一次期末考试 + 一套分析参数”的分析任务。
3. 姓名字段默认允许为空；AI 调用只传匿名学号或内部 ID，不传真实姓名。
4. 若未配置 DeepSeek API Key，系统自动回退到规则生成的分析文字，不阻塞导出和前端展示。
5. 示例数据采用单学期（2025-2026-1），6 门课程、2 个班、60 名学生，满足完整演示需要。
6. 若未导入逐题得分，系统会基于总分比例生成演示级估算题目得分，便于跑通图表与 OBE 页面；正式使用时仍建议导入真实逐题得分。
7. 默认数据库为 SQLite，可通过 `DATABASE_URL` 切换 PostgreSQL。
8. 当前数据库迁移采用“启动时补列”的轻量方案，后续生产化建议接入 Alembic。
9. 老师提供的 Excel / Word 模板被视为业务参考模板，当前版本优先对齐字段结构与分析内容，不保证百分百复刻原始排版细节。
10. 前端构建建议使用 Node.js LTS；若本机环境较新导致额外兼容问题，以 `npm run build` 是否通过为准。
