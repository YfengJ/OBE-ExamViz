# 指标计算方法

本文档只保留当前系统已经真正落地实现、并能在答辩中清楚解释的指标与处理流程。

## 1. 数据输入口径

系统以一次 `AnalysisRun` 为计算单位。单个分析任务包含：

- 课程
- 班级
- 期末考试
- 平时成绩
- 期中成绩
- 期末总分
- 试卷结构
- 逐题得分

其中：

- 平时、期中、期末用于计算课程总评
- 期末总分用于成绩分布与卷面难度分析
- 逐题得分 + 题目结构用于题目分析与 OBE 达成度分析

## 2. 成绩统计指标

设某班共有 \(n\) 名学生，期末总分为 \(x_i\)。

### 2.1 平均分

\[
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i
\]

### 2.2 最高分

\[
x_{max} = \max(x_1, x_2, \dots, x_n)
\]

### 2.3 最低分

\[
x_{min} = \min(x_1, x_2, \dots, x_n)
\]

### 2.4 及格率

\[
PassRate = \frac{\text{期末成绩} \ge 60 \text{的人数}}{n}
\]

系统前端显示为百分比。

### 2.5 分数段人数与占比

系统按如下分段统计人数与占比：

- `90-100`
- `80-89`
- `70-79`
- `60-69`
- `<60`

某一分数段占比计算为：

\[
Rate_k = \frac{Count_k}{n}
\]

## 3. 课程总评计算

设某学生平时成绩为 \(u_i\)，期中成绩为 \(m_i\)，期末成绩为 \(f_i\)。
权重分别为：

- 平时权重 \(w_u\)
- 期中权重 \(w_m\)
- 期末权重 \(w_f\)

则课程总评为：

\[
Total_i = u_i \times w_u + m_i \times w_m + f_i \times w_f
\]

当前系统默认：

- \(w_u = 0.2\)
- \(w_m = 0.2\)
- \(w_f = 0.6\)

用户可在创建分析任务时修改。

## 4. 试卷难度判断

设卷面满分为 \(F\)，班级期末平均分为 \(\bar{x}\)，则卷面平均得分率为：

\[
P = \frac{\bar{x}}{F}
\]

系统采用以下规则给出难度标签：

- \(P \ge 0.8\)：容易
- \(0.6 \le P < 0.8\)：中等
- \(P < 0.6\)：较难

这个标签用于老师模板中的“试题难度”文字描述。

## 5. 题目分析指标

设第 \(j\) 题满分为 \(S_j\)，第 \(i\) 个学生在该题得分为 \(q_{ij}\)。

### 5.1 题目平均分

\[
\bar{q_j} = \frac{1}{n}\sum_{i=1}^{n} q_{ij}
\]

### 5.2 题目得分率

\[
R_j = \frac{\bar{q_j}}{S_j}
\]

系统前端展示时用百分比表示。

### 5.3 题目及格率

系统定义某题“及格”条件为：

\[
q_{ij} \ge 0.6 \times S_j
\]

则该题及格率为：

\[
Pass_j = \frac{\text{满足及格条件的人数}}{n}
\]

### 5.4 区分度

当前系统使用“题目得分与学生总分的皮尔逊相关系数”作为区分度近似指标：

\[
Disc_j = corr(q_j, T)
\]

其中：

- \(q_j\)：全班学生第 \(j\) 题得分向量
- \(T\)：全班学生总分向量

说明：

- 值越高，说明该题越能区分高分学生与低分学生
- 若该题所有学生得分完全相同，则区分度按 0 处理

## 6. 题型 / 题组分析

若若干题目属于同一题组（如单选题、填空题、综合题），设该题组总满分为 \(G\)，题组内学生平均得分为 \(\bar{g}\)，则题组达成度为：

\[
GroupAchievement = \frac{\bar{g}}{G}
\]

这部分用于前端“题型平均得分率”图表。

## 7. OBE 课程目标达成度

### 7.1 单个学生某课程目标成绩

若课程目标 \(CO_k\) 关联若干题目，学生在这些题目的得分总和为：

\[
COScore_{ik} = \sum q_{ij}
\]

对应题目满分总和为：

\[
COFull_k = \sum S_j
\]

则学生在该课程目标上的达成度为：

\[
COAchievement_{ik} = \frac{COScore_{ik}}{COFull_k}
\]

### 7.2 班级课程目标平均分

\[
COAvg_k = \frac{1}{n}\sum_{i=1}^{n} COScore_{ik}
\]

### 7.3 班级课程目标达成度

\[
COClassAchievement_k = \frac{COAvg_k}{COFull_k}
\]

### 7.4 是否达成

设课程目标阈值为 \(\theta_k\)，当前系统默认值为 `0.65`。

若：

\[
COClassAchievement_k \ge \theta_k
\]

则判定该课程目标“达成”。

### 7.5 权重与最终结果

系统允许题目携带 `co_weight`。
同一课程目标的总权重记为 \(W_k\)，全体课程目标权重和为：

\[
W = \sum_k W_k
\]

则课程目标 \(CO_k\) 的归一化权重为：

\[
Weight_k = \frac{W_k}{W}
\]

最终结果为：

\[
Result_k = Weight_k \times COClassAchievement_k
\]

这与老师模板中的“权重”和“达成结果”列对应。

## 8. 预警规则

当前系统实现的是规则预警，不做尚未落地的预测模型。

### 8.1 严重预警

满足以下任一条件：

- 期末卷面成绩 `< 60`

### 8.2 一般预警

满足以下任一条件：

- 期末卷面成绩 `< 70`
- 课程总评 `< 65`

### 8.3 预警输出

每条预警保留：

- 学号
- 匿名姓名字段
- 期末卷面成绩
- 课程总评
- 预警等级
- 原因列表

## 9. DeepSeek 文字分析生成

系统采用“规则文本 + DeepSeek 润色”的两段式策略：

1. 先基于统计指标生成结构化初稿
2. 若配置了 DeepSeek API，则用以下输入生成最终建议：
   - 课程与班级元信息
   - 分数统计
   - 课程目标达成情况
   - 重点预警学生数量

输出文字分为四段：

- 成绩统计摘要
- 课程目标支撑度分析
- 课程目标达成度分析
- 持续改进建议

## 10. 计算流程

### 10.1 导入阶段

1. 导入学生名单
2. 导入平时 / 期中 / 期末成绩
3. 导入试卷结构
4. 导入逐题得分
5. 更新 `AnalysisRun` 快照

### 10.2 分析阶段

1. 计算期末统计指标
2. 计算分数段分布
3. 计算题目分析
4. 计算题型分析
5. 计算课程总评
6. 计算课程目标达成度
7. 识别预警学生
8. 生成规则文字 / AI 文字

### 10.3 导出阶段

1. 汇总成绩单
2. 汇总班级分析主表
3. 汇总课程目标平均分和达成度
4. 生成课程目标图表
5. 写入文字分析 sheet
