# 用户使用手册

## 1. 适用场景

本系统适用于教师或专业负责人完成某门课程某个班级的期末试卷分析工作，尤其适合需要输出“课程目标达成度 + 班级成绩统计 + 持续改进建议 + Excel 分析表”的场景。

## 2. 启动系统

### 2.1 后端

在项目根目录执行：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2.2 前端

```bash
cd frontend
npm install
npm run dev
```

浏览器打开：

- 前端：`http://localhost:5173`
- 后端文档：`http://localhost:8000/docs`

## 3. 使用流程

### 两种输入模式

系统现在支持两种正式输入模式：

1. 标准化结构化输入
适合按系统规范逐步导入学生名单、成绩、试卷结构和逐题得分，最终输出 Excel、Word、图表和预警建议。

2. 老师整份工作簿输入
适合已经拿到老师整理好的整份 `.xlsx` 工作簿。系统会先识别输入内容，再生成严格模板 Word 报告，并自动追加可视化补充页。

### 步骤 1：进入分析任务页

首页是“分析任务工作台”。
先选择课程、期末考试、班级，填写学年、教师、OBE 阈值和成绩权重，然后点击“创建任务”。

创建后，系统会生成一条 `AnalysisRun`，这条任务就是后续导入、分析、导出的统一上下文。

### 步骤 2：导入数据

进入“导入向导”页面，按如下顺序导入：

1. 学生名单
2. 平时成绩
3. 期中成绩
4. 期末成绩
5. 试卷结构
6. 逐题得分

如果只是快速演示，也可以直接使用系统自带的样例数据。
导入向导页面底部同时提供模板下载按钮，可以直接获取标准 CSV 模板。

如果你使用“老师整份工作簿输入”模式，则不需要这 6 步逐项导入。
在导入向导中进入“老师工作簿输入模式”，先上传 `.xlsx` 进行识别预览；系统会显示：

- 识别到的课程、班级、教师、学生数
- 成绩统计和试题难度
- 识别到的课程目标数量、题型数量
- 当前支持输出的报告类型

确认无误后，再点击“生成最终报告”。

### 步骤 3：查看分析结果

进入“分析结果”页面，可以查看：

- 平均分、及格率、试题难度标签
- 分数段分布图
- 题型平均得分率
- 课程总评构成
- 课程目标平均分和达成度
- 逐题分析

### 步骤 4：查看改进建议

进入“改进建议”页面，查看：

- 规则预警名单
- 成绩统计摘要
- 课程目标支撑度分析
- 课程目标达成度分析
- 持续改进建议

如果已配置 DeepSeek API，可以点击“生成 AI 增强建议”获得更自然的文字稿。若未配置，系统会继续返回规则生成的默认建议文本。

### 步骤 5：导出分析材料

在“分析结果”页面可以下载两类结果：

- `导出模板 Excel`
- `导出试卷分析文档`

## 4. 推荐导入模板

### 4.1 学生名单

推荐字段：

- `student_no`
- `name`
- `class_name`
- `major`
- `grade_year`

### 4.2 平时 / 期中成绩

推荐字段：

- `student_no`
- `score`

### 4.3 期末成绩

推荐字段：

- `student_no`
- `total_score`

### 4.4 试卷结构

推荐字段：

- `qno`
- `qtype`
- `qgroup_name`
- `sub_qno`
- `score`
- `section`
- `knowledge_point`
- `co_code`
- `indicator_code`
- `co_weight`
- `expected_threshold`

### 4.5 逐题得分

推荐字段：

- `student_no`
- `exam_id`
- `qno`
- `score`

## 6. 常见问题

### 6.1 后端启动时报 `No module named 'backend'`

原因：你在 `backend/` 目录下启动了 `uvicorn backend.app.main:app`。
解决：回到项目根目录再启动。

### 6.2 没有配置 DeepSeek API 会怎样

系统仍然能正常运行，只是“AI 建议”会回退到规则文本。

### 6.3 为什么导入后任务状态没变化

当前版本会在导入后自动刷新任务快照；如果页面未及时更新，点击页面上的“刷新”按钮即可。

### 6.4 示例数据里的姓名为什么是空的

为了默认脱敏演示，`name` 字段允许为空，AI 分析默认只使用学号。
