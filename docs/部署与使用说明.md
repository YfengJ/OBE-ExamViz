# OBE 期末试卷分析系统部署与使用说明

本文档用于说明如何在一台电脑上部署和使用“OBE 期末试卷分析系统”。

## 一、交付包内容

交付包中包含：

- `backend/`：后端服务代码，负责成绩导入、课程目标计算、报告生成和 Word 导出。
- `frontend/`：前端页面代码，负责系统操作界面。
- `backend/templates/teacher_input_template.xlsx`：简洁成绩输入模板。
- `backend/templates/teacher_report_template.docx`：Word 试卷分析表版式模板。
- `.env.example`、`backend/.env.example`、`frontend/.env.example`：环境变量示例文件，只包含占位值。
- `README.md`、`README.zh-CN.md`、`CHECKLIST.md`、`docs/部署与使用说明.md`：说明文档和检查清单。
- `sample_data/`：公开模拟数据，仅用于本地测试，不代表真实学生或真实课程。


## 二、运行环境要求

建议环境：

- Python 3.10 或以上版本。
- Node.js 18 或以上版本。
- npm 9 或以上版本。
- 操作系统可使用 Windows、macOS 或 Linux。

如果只安装了 Python 3.12，也可以正常部署。当前依赖文件会在 Python 3.12 下自动安装兼容的 `numpy==1.26.4`，避免旧版 `numpy==1.24.3` 触发源码编译失败。

如电脑未安装 Python 或 Node.js，需要先安装后再继续。

## 三、后端部署

以下命令均在项目根目录执行，也就是能看到 `backend/` 和 `frontend/` 的目录。

1. 创建 Python 虚拟环境：

```bash
python -m venv .venv
```

Windows 如果没有 `py` 命令，直接使用 `python -m venv .venv` 即可。

2. 激活虚拟环境：

Windows：

```bash
.venv\Scripts\activate
```

macOS / Linux：

```bash
source .venv/bin/activate
```

3. 安装后端依赖：

```bash
pip install -r backend/requirements.txt
```

4. 创建后端环境配置：

```bash
cp backend/.env.example .env
```

Windows 如果不能使用 `cp`，可以手动复制 `backend/.env.example`，重命名为 `.env`，放到项目根目录。

5. 启动后端：

```bash
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

启动成功后，可访问：

- 后端健康检查：`http://127.0.0.1:8000/api/v1/health`
- 后端接口文档：`http://127.0.0.1:8000/docs`

第一次启动时，系统会自动创建本地数据库 `obe_analysis.db`。该数据库只保存在本机，不包含在交付包中。

## 四、前端部署

重新打开一个终端窗口，进入项目根目录后执行：

```bash
cd frontend
npm install
npm run dev
```

启动成功后，浏览器访问：

```text
http://127.0.0.1:5173
```

如果后端端口不是 `8000`，可复制 `frontend/.env.example` 为 `frontend/.env`，并修改：

```env
VITE_API_PROXY_TARGET=http://127.0.0.1:8000
VITE_API_TIMEOUT_MS=60000
```

修改后重新运行 `npm run dev`。

## 五、DeepSeek API Key 配置

系统可以不配置 API Key。未配置时，系统仍可完成成绩导入、课程目标达成度计算、结构分析和 Word 报告导出，只是 AI 生成文字会使用规则兜底内容。

如果需要使用 DeepSeek 生成更完整的报告文字和教学改进建议，请编辑项目根目录的 `.env`：

```env
DEEPSEEK_API_KEY=这里填写自己的Key
DEEPSEEK_API_BASE=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
AUTO_SEED_DEMO_DATA=false
```

注意：

- `.env` 不要发给别人。
- API Key 不要写入代码、文档截图或压缩包。
- 更换电脑部署时，应重新在新电脑上创建 `.env`。


## 六、基本使用流程

1. 打开系统首页。
2. 进入“课程参数”，可手动新增课程，也可上传教学大纲自动新建课程。
3. 进入“数据导入”，下载“成绩输入模板”。
4. 按模板填写：
   - 基本信息
   - 试卷结构
   - 课程目标
   - 学生成绩
5. 上传填写后的成绩输入模板。
6. 预览识别结果，确认无误后导入并开始计算。
7. 进入“结构分析”，检查成绩分布、题型表现和课程目标达成度。
8. 进入“AI 建议”，选择建议模板并生成教学改进建议。
9. 进入“报告预览”，生成报告正文。
10. 检查报告内容无误后，点击“导出报告”下载 Word 试卷分析表。

## 七、成绩输入模板说明

模板位于：

```text
backend/templates/teacher_input_template.xlsx
```

系统只要求填写生成报告必需的原始数据，不需要老师手动填写平均分、分数段、达成度和图表。

主要工作表：

- `基本信息`：填写课程、班级、教师、学期、考试日期等。
- `试卷结构`：填写题号、题型、小题号、满分和对应课程目标。
- `课程目标`：填写课程目标编号、指标点、课程目标说明和达成阈值；如果已通过教学大纲建课，课程目标说明可减少重复填写。
- `学生成绩`：填写学号、姓名和每道题得分。

系统会自动计算：

- 期末总分
- 平均分、最高分、最低分、及格率
- 分数段人数和比例
- 题型平均得分率
- 课程目标平均分和达成度
- 图表和 Word 报告正文

## 八、常见问题

### 1. 前端页面打不开

请确认前端命令窗口中 `npm run dev` 正在运行，并访问：

```text
http://127.0.0.1:5173
```

### 2. 页面打开后接口报错

请确认后端命令窗口中 `uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000` 正在运行。

也可以访问：

```text
http://127.0.0.1:8000/api/v1/health
```

如果返回 `healthy`，说明后端正常。

### 3. 生成 AI 建议较慢

AI 建议和报告正文需要调用外部模型，可能耗时十几秒到几十秒。系统前端默认等待时间为 60 秒。

### 4. 没有 API Key 能否使用

可以。没有 API Key 时，系统仍可导入成绩、完成计算、查看图表并导出 Word 报告，只是 AI 文案会使用系统规则生成的兜底文本。

### 5. 想重新开始一门课

可以直接在系统中新增课程并上传新的模板。如果要彻底清空本机所有数据，关闭后端后删除：

```text
obe_analysis.db
```

然后重新启动后端。

### 6. 导入失败怎么办

优先检查：

- 是否使用系统下载的简洁输入模板。
- `基本信息` 是否填写课程名称、班级、任课教师和学期。
- `试卷结构` 中题型、满分、课程目标编号是否完整。
- `学生成绩` 中得分列标题是否与 `试卷结构` 对应。
- 是否存在空白学号、重复学号或非数字成绩。

## 九、交付前检查

如果需要确认系统是否完整，可在项目根目录运行：

```bash
./scripts/verify_delivery.sh
```

该脚本会检查：

- 代码补丁格式
- AI 隐私相关风险关键词
- 后端自动化测试
- 前端生产构建

如果全部通过，说明当前版本可正常交付。
